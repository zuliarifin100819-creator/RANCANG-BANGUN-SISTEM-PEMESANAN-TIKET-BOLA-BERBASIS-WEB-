# LagaKita — Pemesanan Tiket Bola

Purwarupa antarmuka web untuk proyek pembelajaran **Wireless Computing**. Saat ini mencakup halaman beranda dan daftar pertandingan dengan data simulasi.

## Fitur yang tersedia

- Beranda dengan hero, sorotan pertandingan, dan navigasi.
- Daftar pertandingan dengan pencarian nama tim/stadion.
- Filter kompetisi.
- Kartu jadwal dengan stadion, waktu, harga awal, dan tiket simulasi.
- Tampilan responsif untuk ponsel dan desktop.

## Menjalankan proyek

Tidak perlu instalasi paket. Unduh atau clone repositori, lalu buka `index.html` di browser. Navigasi **Pertandingan** membuka `pertandingan.html`.

## Berkas

- `index.html` — halaman beranda.
- `pertandingan.html` — daftar dan filter pertandingan.
- `styles.css` — gaya dan layout responsif.
- `app.js` — data simulasi dan interaksi pencarian/filter.

## Data dan batasan

Pertandingan, tanggal, stadion, harga, dan jumlah tiket adalah data contoh. Proyek ini bukan layanan resmi dan belum memiliki backend, autentikasi, pembayaran, atau penyimpanan pesanan. Tombol pemilihan tiket saat ini menampilkan pemberitahuan bahwa formulir pemesanan akan dibuat pada tahap berikutnya.

## Pengembangan berikutnya

- Sambungkan tombol pemilihan tiket ke halaman formulir pemesanan.
- Tambahkan halaman admin.
- Tambahkan backend dan basis data bila disepakati kelompok.
- Ganti data contoh dengan data yang disetujui kelompok.
